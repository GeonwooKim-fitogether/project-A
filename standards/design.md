# 디자인 기준서

> 한 줄 요지: **독립 HTML 문서·보고 산출물은 사내 문서 디자인 시스템 1.0 을 그대로 재사용하고, 색·서체·폭·표·탭 스타일을 문서마다 새로 설계하지 않음.** 바꾸는 것은 제목·내용·도식뿐이며, 숫자·제품명·일정은 내용 원본에서만 가져옴.

- 적용: 독립 HTML 보고서·브리프·기획 문서, 건우님께 올리는 시각 산출물

## ③ 고정 시각 규칙

| 구분 | 기준 |
|---|---|
| 색 | 페이지 `#eff3f4` · 표면 `#ffffff` · 잉크 `#0a1316` · 보조 글자 `#44555f` · 회색 `#aabaca` · 선 `#d5dee4` · 짙은 면 `#1a2c34` · 청록 `#7ccbd2`(선택·연결 강조에 한정) |

| 서체 | 공식 서체는 브랜드 지정 서체. 독립 HTML 은 템플릿 내장 Pretendard 사용, 임의 변경 금지 |
| 글자 크기 | 본문 16px(줄 간격 1.75), 표·설명 14px 이상, 라벨 12px 이상, H1 40~72px, H2 28~40px, H3 21~23px |
| 폭·간격 | 최대 1,280px, 좌우 여백 48 → 32 → 20px(모바일). 간격 4/8/12/16/24/32/48/64/96px, 선 1px, 모서리 0~4px |

| 로고·사진 | 제공된 공식 자산만 사용, 로고를 글꼴로 흉내 내지 않음. 자산 없으면 회사명 텍스트로 표시, 생성한 인물·장비·가짜 화면 금지 |
| 상태 표시 | 색만으로 구분하지 않고 글자·기호 병기. 보고용 상태 색은 [보고 기준서](./report.md) 3절을 따름 |

## ④ 구성 요소와 구조

- 템플릿 기본 구조를 유지함: `data-ft-system="1.0"`, `body.ft-doc`, `style#ft-system`
- 내장 폰트·로고의 base64 는 읽거나 다시 쓰지 않고 그대로 보존함
- 요소: 요약 `.ft-lead` · 표 `.ft-table-wrap` · 2~3개 비교 `.ft-grid`/`.ft-panel` · 상세 근거 `details.ft-details` · 관계도 `.ft-diagram` · 탭 `.ft-tabs` · 수치·목표 `.ft-goals` · 보충 `.ft-note`
- 특별한 요소가 필요하면 페이지 전용 클래스를 추가하고 공통 변수·CSS 를 덮어쓰지 않음
- 공통 규칙 변경은 가이드 버전 갱신으로만 처리함

## ⑤ 문구 기준

- 말투는 Decisive & Motivating: 결론 먼저, 구체적인 질문과 동사 사용
- 실제 데이터 · 예시 · 목표 · 계획 · 검토 중인 안을 구분해 표시함
- 수치에는 단위·기간·분모·비교 조건을 표시함, 예시 숫자는 예시임을 표시함
- 검증되지 않은 성과·최고·최초·무조건·즉시 등의 주장 금지
- 핵심 내용은 기본 화면에 두고 긴 근거만 상세 펼침에 넣음
- 본문에 편집 이력·작업 로그·제작 과정 설명을 넣지 않음

## ⑥ 출력·검증 기준

- 독립 HTML 한 파일로 CSS·JS·폰트·이미지가 동작함, 외부 CDN·폰트·차트 라이브러리 의존 금지
- JavaScript 없이도 본문·표·결론이 읽힘
- 1,440 · 768 · 390 · 320px 에서 가로 넘침·글자 잘림 없음(넓은 표 내부 스크롤은 허용)
- 키보드로 목차·탭·펼침·버튼 사용 가능, `focus-visible` 유지, 본문 대비 4.5:1 이상
- `prefers-reduced-motion` 존중, 인쇄 시 핵심 본문과 상세 근거 유지
- 동일 내용의 MD 와 HTML 을 함께 전달하고 숫자·일정·상태를 일치시킴
- 확인하지 못한 항목은 "검증 완료"로 표시하지 않고 확인 범위를 짧게 보고함
