# 에스컬레이션 기준 — 언제 멈추고 건우님을 부르나

> 한 줄 요지: **크리티컬이 아니면 자율로 진행하고, 문제가 되면 원복한다.** 아래 표에서 '건우님'인 항목은 작업을 멈추고 세 문장으로 보고한 뒤 허락을 기다린다. '자율'인 항목은 스스로 처리하고, 정상 결과는 이슈 댓글만 남긴다.

이 파일은 project-A 자율 루프 전용이다. 창고의 [에스컬레이션 규칙](./escalation.md)과 [자율 병합 등급](./autonomy-tiers.md)을 대체하지 않으며, 둘이 겹치면 **더 엄격한 쪽**이 이긴다. 에스컬레이션 규칙 2절 트리거 6(main 머지)은 하·중에 한해 자율 병합 등급이 대체한다는 점은 그대로다.

## 1. 기준 표 — 멈추는 경우와 스스로 하는 경우

| 상황 | 누가 | 행동 |
|---|---|---|
| 하·중 등급 변경(문서·제품 밖 설정·테스트·일반 기능·버그 수정) | **자율** | 검사 통과 후 병합한다. 문제가 생기면 먼저 원복하고 즉시 보고한다. |
| 데이터베이스 구조·마이그레이션, 실환경 데이터 쓰기 | **건우님** | 실행하지 않는다. Draft PR 로만 두고 보고한다. |
| 운영 배포 | **건우님** | 배포하지 않는다. Draft PR 로만 두고 보고한다. |
| 권한·설정·훅·규칙 변경(`.claude/settings.json` 의 permissions, `.claude/hooks/`, `.claude/rules/`) | **건우님** | Draft PR 로만 두고 병합하지 않는다. 스스로 권한을 넓히지 않는다. |
| 시크릿(토큰·암호·자격 증명) | **건우님** | 채팅·이슈·PR 에 값을 적지 않고 멈춘다. |
| 돈(결제·청구·정산·유료 플랜) | **건우님** | 결제하거나 유료 자동화를 켜지 않고 멈춘다. |
| 외부 메시지(이메일·Slack·WeChat) | **건우님** | 보내지 않는다. 초안만 준비해 보고하고, 발송은 건우님이 한다. |
| 데이터 삭제, 또는 브랜치를 직접 삭제 | **건우님** | 실행하지 않는다. 머지된 브랜치 삭제는 워크플로에 맡긴다. |
| 같은 검사가 두 번 실패 | **건우님** | 세 번째를 돌리지 않고 멈추고 보고한다. |
| 하·중 변경의 원복이 필요하고, 되돌릴 수 있다 | **자율** (즉시 보고) | [자율 병합 등급](./autonomy-tiers.md) 5절대로 먼저 되돌리고, 나쁜 소식을 즉시 보고한다. |
| 원복이 막힌다(충돌, DB·운영과 어긋남, 원래 PR 이 상, 되돌림 PR 실패) | **건우님** | 되돌리거나 우회하지 않고 멈추고 보고한다. |
| 범위를 어떻게 잡느냐에 따라 결과가 달라지는 애매함 | **건우님** | 추측으로 진행하지 않고 멈추고 보고한다. |
| 가드 훅이 명령을 막는다(`branch-guard`, `sql-write-guard` 등) | **건우님** | 가드를 우회하거나 끄지 않고 멈추고 보고한다. |

애매하면 '건우님'으로 올린다. 표에 없는 상황도 상 목록([자율 병합 등급](./autonomy-tiers.md) 1절)에 닿으면 건우님이다.

## 2. 보고 — 세 문장, 나쁜 소식은 즉시

보고는 **작업 이슈의 댓글 하나, 세 문장**이다. 상이면 같은 내용을 Draft PR 본문(또는 댓글)에도 적는다. Grok 쪽 결과 확인 루틴이 이슈와 PR 을 읽어, 문제가 있을 때만 Wayfinder 방에 알린다. 하·중 병합처럼 정상인 처리는 이슈 댓글만 남기고 방을 울리지 않는다.

1. **문제** — 무엇이 필요했거나 무엇이 어긋났나.
2. **한 일 또는 제안** — 무엇을 했거나, 상을 무엇으로 고치자고 제안하나. PR 링크와 등급을 함께 적는다.
3. **다음 단계와 필요한 허락** — 다음에 무엇을 하나, 건우님의 허락이 필요하면 무엇인지 한 줄. 필요 없으면 "허락은 필요 없다"고 적는다.

나쁜 소식(검사 실패, 원복, 가드 차단, 상 등급 발견)은 미루지 않고 바로 올린다. 허락을 기다리는 동안, 그 결정에 의존하지 않는 다른 작업은 계속한다.

이 루프의 기본 채널은 세 문장 보고다. 창고 에스컬레이션 규칙의 결정 카드는 옵션이 여러 개라 비교가 필요할 때만 세 문장 뒤에 붙인다.

## 적용 범위

- 이 저장소(project-A)의 모든 세션에 적용된다. 창고 원본이 아니므로 동기화 봇이 이 파일을 덮어쓰지 않는다. 고칠 때도 이 저장소에서 고친다.
- 이 파일을 바꾸는 것 자체는 상 등급이다. Draft PR 로만 두고 건우님이 결정한다.
